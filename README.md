# calculadora-hexadecimal
Este programa solicita por teclado dos valores numéricos compuestos por un byte en formato hexadecimal (rango 00h a FFh) y un operador aritmético (Suma + o Resta -). La aplicación ejecutará la instrucción nativa correspondiente (ADD o SUB) directamente sobre los registros de uso general de la CPU y mostrará el resultado final en pantalla.
